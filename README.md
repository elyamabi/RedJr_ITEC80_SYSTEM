# RedJr Builders and Construction Supply — ITEC 80 Prototype

## Files
- `index.html` — page structure and content.
- `styles.css` — styling, layout, colors, and responsive design.
- `script.js` — interactive behavior and sample data.
- `USABILITY_EVALUATION.md` — usability task checklist, issues, and proposed improvements.
- `SCREENSHOT_GUIDE.md` — screenshot checklist for submission.

## Run
1. Keep all three code files (`index.html`, `styles.css`, and `script.js`) in the same folder.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Use the prefilled demo credentials:
   - Email: `admin@redjr.test`
   - Password: `redjr123`

No installation or internet connection is required.

## Main features
- Login screen (demo only)
- Dashboard and recent orders
- Product catalog with search and category filters
- Cart quantities, order review, and confirmation
- Order list and status updates
- Inventory and stock updates
- Reports and CSV export
- Activity history
- Responsive mobile navigation

## HCI principles
Consistency, visibility, feedback, user control, error prevention, clear navigation, and visual hierarchy.

## Limitations
This is a browser-only classroom prototype. Data resets on refresh; there is no real authentication, backend database, payment processing, or live business connection. Use fictional information during demonstrations.
